## Como gerar de novo ou editar

Os textos ficam em `engine/data.js` e as ilustrações em `engine/art.js`. Depois de editar:

```bash
node engine/render.js <id> saida   # ex.: node engine/render.js 3 saida
```

Precisa de Node com Playwright (Chromium), Python 3 com numpy e ffmpeg.
